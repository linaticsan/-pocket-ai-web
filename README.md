# Pocket AI Web

Public, static, installable Pocket AI workspace for personal use on iPhone.

## Included

- Chat — connects to your own Gemini API key for the current page session only.
- Local AI — connects to an OpenAI-compatible local server you control.
- Files — opens and downloads simple text files locally.
- GitHub — searches public GitHub repositories without storing a GitHub token.
- Surface Search — searches Internet Archive, Wikimedia Commons, Crossref, and optional YouTube.

## Privacy and keys

No API keys are committed to this repository. Gemini keys are kept only in page memory. An optional YouTube Data API key can be saved in this browser's local storage. Restrict any API key at the provider before using it.

## GitHub Pages

This repository is designed to publish directly from the `main` branch root with GitHub Pages. After Pages is enabled, open the Pages URL in Safari and use **Share → Add to Home Screen**.
