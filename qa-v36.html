V36 changes made after testing

Mobile navigation was the largest usability risk: eight destinations were being squeezed into one iPhone bottom bar. V36 keeps Home, Chat, Library and Files visible and moves Local AI, Code, GitHub and Research into a one-tap More sheet. It also adds keyboard focus states, network status feedback, a selected-book badge, safer touch targets, reduced-motion handling and calmer transitions.

What this report does not pretend to test

The 100 rounds are deterministic code/feature checks, not 100 physical iPhone sessions and not 100 paid/external AI calls. Live model downloads, WebGPU behavior, third-party API quotas/CORS, external search availability and actual generated answer quality depend on the device and external services. Those need real-device/network testing.

This distinction is intentional so the report does not claim tests that were not actually performed.

Quick manual smoke test

On your iPhone: open Pocket AI → tap Library → import one PDF → select it → make a Quiz → export it → open More → test Local AI, Code, GitHub and Research. If any real-device issue appears, take a screenshot and it can be fixed against the exact screen state.
